# Canonical Identity

## Canonical naming

- `CeloHT` = the active project
- `Celo-HaiTi` = the canonical GitHub organization
- `Celo-HT` = obsolete and prohibited in the current editable corpus

## Canonical currency terminology

- `USDm` = the current canonical stable-value currency terminology
- `cUSD` = obsolete and prohibited in the current editable corpus

## Rules

1. Never replace, remove, rename, or alter `CeloHT`.
2. Never replace, remove, rename, or alter `Celo-HaiTi`.
3. Only the obsolete form `Celo-HT` must be eliminated from current editable files.
4. Current editable files must not contain visible obsolete `cUSD` terminology.
5. Historical Git history may retain obsolete terminology, but current editable files must follow the canonical vocabulary.

## Scope

This policy applies to current README files, Markdown files, source files, documentation, configuration, website content, examples, links, changelogs, and other editable repository content. It does not apply to immutable Git history, commit messages, or historical commit objects.
