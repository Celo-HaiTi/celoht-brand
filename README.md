# CeloHT Brand Repository

Official brand, identity, and communication assets for CeloHT, an open-source, Haitian-led, community-governed initiative focused on financial inclusion, digital literacy, and sustainable development in Haiti.

[![License: Apache 2.0](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](./LICENSE)
[![Maintained by CeloHT Community](https://img.shields.io/badge/Maintained%20by-CeloHT%20Community-1B2A4A)](https://celoht.com)

---

## Overview

CeloHT is an open-source, community-driven initiative that uses blockchain infrastructure as a tool for access, education, and practical inclusion. The work is rooted in Haitian Creole communication, local trust-building, and long-term community development.

This repository is the canonical source for:

- visual identity and logo guidelines
- messaging and tone standards
- color, typography, and brand system usage
- media, press, and community-facing communications
- governance and mission-aligned documentation for public use

This is a brand and documentation repository. It is not a product, wallet, dApp, smart contract, or treasury implementation repository.

---

## What CeloHT Stands For

CeloHT is guided by three core pillars:

| Pillar | Purpose |
|---|---|
| 🎓 Education | Web3 and financial literacy, mainly in Haitian Creole |
| 🤝 Agent Network | Local support for digital financial access and onboarding |
| 🌱 Reforestation | Sustainable community development and environmental impact |

CeloHT is not:

- a cryptocurrency
- a token project
- an investment platform
- an official affiliate of the Celo Foundation or Valora

CeloHT uses Celo network infrastructure as a technical choice, not as a formal endorsement or partnership. The project has no native token, no ICO, no presale, no staking token, and no investment promises.

---

## Purpose of This Repository

This repository exists to ensure that CeloHT presents itself consistently, credibly, and accessibly wherever the name, logo, or message appears.

It provides the single source of truth for:

- brand identity and visual consistency
- writing guidance and public tone
- asset rules and legal-safe use of names and marks
- community communication standards and shared understanding

## Brand Principles

CeloHT's identity is shaped by these principles:

- Open source and transparent
- Community-led and accountable
- Accessible to users who are new to digital finance and Web3
- Grounded in trust rather than hype
- Designed to communicate clearly across languages and communities
- Sustainable and durable over time
