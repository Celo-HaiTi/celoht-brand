## What is CeloHT?

CeloHT is a Haitian-led, community-governed, open-source social-impact initiative focused on financial inclusion, blockchain education, and environmental sustainability in Haiti. It is built on the Celo blockchain ecosystem as an infrastructure choice. **CeloHT is not affiliated with Celo Foundation or Valora, is not a cryptocurrency, and is not an investment platform.**

**No Token Policy:** CeloHT has no native token, no ICO, no presale, no staking token, no speculation model, and makes no investment promises. It uses only existing Celo network assets, including USDm and CELO for network use.

CeloHT is organized around three permanent pillars:

| Pillar | Purpose |
|---|---|
| 🎓 **Education** | Web3 and financial literacy education, delivered primarily in Haitian Creole |
| 🤝 **Agent Network** | Local, human support networks that help communities access digital financial tools |
| 🌱 **Reforestation** | Sustainable development and environmental impact tied to community growth |

Learn more: [celoht.com](https://celoht.com) · Organization: [github.com/Celo-HaiTi](https://github.com/Celo-HaiTi) · Repository: [github.com/Celo-HaiTi/celoht-brand](https://github.com/Celo-HaiTi/celoht-brand)

## What This Repository Is

This repository is the canonical source for CeloHT's brand identity and public presentation. It contains:

- visual identity guidance
- logo and asset usage rules
- messaging and tone guidance
- media and press materials
- brand documentation and reference standards

This repository is intentionally not a product implementation repository. It does not contain wallet software, dApp logic, smart contracts, backend services, or payment-processing infrastructure.

## What This Repository Is Not

This repository is not:

- a smart-contract repository
- a wallet or dApp runtime
- a treasury or payment backend
- a blockchain deployment repository
- a token or financial product implementation

Any operational wallet, blockchain, or product functionality must be verified in the relevant application or ecosystem repository under the Celo-HaiTi organization.

## Why This Repository Exists

A strong visual identity builds trust with the communities CeloHT serves, with contributors, NGOs, universities, partners, and media. This repository is the **single source of truth** for how CeloHT looks, sounds, and presents itself anywhere in the world.

If you are building any material that carries the CeloHT name or mark - a slide deck, a banner, a partner page, merchandise, or a presentation - this repository tells you exactly how to do it correctly.

## Core Principles

CeloHT's identity is built on:

- **Open Source** - everything here is free to use under the terms in [LICENSE](./LICENSE) and [LOGO_GUIDELINES.md](./LOGO_GUIDELINES.md)
- **Transparency** - no hidden agendas, no dark patterns, no confusing disclaimers
- **Community First** - this repository belongs to the CeloHT community, not one individual
- **Financial Inclusion & Education** - the visual identity must feel accessible to first-time smartphone users, not just crypto-native audiences
- **Sustainability** - CeloHT's brand should age well and require minimal redesign over the years
- **Non-Affiliation** - CeloHT clearly and consistently discloses that Celo blockchain and Valora wallet compatibility is a technical choice, not an endorsement or partnership
